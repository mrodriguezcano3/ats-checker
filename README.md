# ATS-Checker 🚀

Un motor de análisis y evaluación de currículums (ATS Parser & Matcher) diseñado para medir la afinidad entre el perfil de un candidato y una oferta de trabajo.

## 🛠️ Stack Tecnológico
* **Frontend:** React (Vite) + TailwindCSS
* **Backend:** Python + FastAPI
* **Almacenamiento/Caché:** Redis (Sesiones en memoria)

## 🏗️ Arquitectura
El proyecto utiliza una estructura de monorepositorio separando las responsabilidades de la UI y el motor de procesamiento de NLP.
